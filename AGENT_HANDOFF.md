## What The App Does

Pomodoro Guard is a focus timer app with:

- Pomodoro timer and streak tracking
- Firebase auth: guest, email/password, Google, optional Apple
- Firestore-backed user profiles and cloud sync
- Username claiming with uniqueness registry
- Friends, friend requests, leaderboard, friend profiles
- Rooms and friend challenges
- Shop/themes/milestones/admin settings

## Core Architecture

Entry point: [src/main.jsx](C:/Users/AUB/Desktop/personal%20projects%20and%20courses/pomodoro/src/main.jsx)

- App mounts with `BrowserRouter`
- `AuthProvider` wraps `AuthGate`
- `AuthGate` blocks unauthenticated and username-incomplete users
- `AppStateProvider` wraps the routed app
- Startup includes fatal UI fallback for uncaught errors and promise rejections

- Watches Firebase auth state

## Important Product/Behavior Details

- Username is required after first sign-in.
- Username format is enforced in Firestore logic: lowercase `a-z`, `0-9`, `_`, length `3-20`.
- Local cache is used as fallback and initial source for app state.
- Cloud profile fields overwrite local counters once profile is loaded.
- Timer completion awards coins and can unlock milestones.
- Admin default passcode documented in [README.md](C:/Users/AUB/Desktop/personal%20projects%20and%20courses/pomodoro/README.md): `3210`
